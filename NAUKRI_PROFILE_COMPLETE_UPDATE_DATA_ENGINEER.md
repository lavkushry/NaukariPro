## 10. AUTOMATED DAILY PROFILE BUMP STRATEGY

### Why Active Recency Matters on Naukri Resdex
Naukri's recruiter search algorithm (Resdex) applies heavy ranking boosts to candidates who are actively seeking roles. Recruiter search filters default to sorting candidates by **"Last Active"** or filtering strictly for candidates active within the last 1 to 7 days:
- Candidates updated **Today** appear on Page 1 of recruiter queries.
- Candidates inactive for > 15 days experience up to an **80% drop** in search appearances.

### The Autonomous Bump Mechanism (`bump_profile()`)
To ensure continuous Page-1 ranking without degrading profile content, the platform includes an autonomous profile bump engine in `naukari_pro/modules/profile_enhancer.py`:

```python
def bump_profile(self, page, force=False):
    """
    Triggers an authentic update event on Naukri backend to update 'Last Active - Today'.
    Applies a non-destructive micro-toggle to the headline or summary once per day.
    """
```

### Operational Rules of the Daily Bump:
1. **Once-Per-Day Execution Guard:**
   - The engine checks `.naukari_profile_state.json` for `last_bumped_date`.
   - If already bumped on today's date (`YYYY-MM-DD`), the action cleanly exits to avoid spamming the Naukri audit log.
2. **Non-Destructive Micro-Toggle:**
   - Appends or strips a trailing period `.` to the resume headline or toggles a single whitespace character.
   - Saves the field to trigger Naukri's backend timestamp update (`profile_last_updated = NOW()`).
   - Zero keyword loss, zero title alteration, zero recruiter confusion.
3. **Automated Daemon Integration:**
   - Scheduled via `naukaripro-agy.timer` and `agy_schedule_runner.sh` to run during morning recruiter peak search hours (09:15 IST / 03:45 UTC).
   - Recruiter view confirms: **"Profile last updated: Today"**.
